# Cost Controls

- Monthly budget: `MONTHLY_USER_BUDGET_USD` (default 10) via `user_monthly_usage_usd`
- Per-user / per-IP RPM via `consume_rate_limit`
- Concurrent run caps in settings
- Fast / Standard / Heavy builder paths
- Max 2 repairs
- Cheap profiles by default (mini + Grok)
- Circuit breaker on failing providers

Target: Starter ~$20 plan supports ~5 solid agents with interactive Live use.
