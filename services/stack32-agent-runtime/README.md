# stack32-agent-runtime

Shared, versioned runtime SDK for AI agents generated by Stack32.

It provides the building blocks the playbook requires so that generated agents
do not re-implement orchestration:

- **Deterministic orchestrator** (`Orchestrator`) — application-controlled
  reactive tool loop; the model proposes structured tool calls, the runtime
  validates, authorizes, executes and observes.
- **Tool registry + dispatcher** (`ToolRegistry`, `ToolSpec`).
- **Typed state** (`AgentState`, `Message`).
- **Context assembly** (`build_messages`).
- **Security policy** (`SecurityPolicy`) — allowed tools + approval modes,
  enforced outside the model.
- **Budgets** (`RuntimeLimits`) — turn/tool-call/cost caps.
- **Checkpoints** (`Checkpointer`, `InMemoryCheckpointer`).
- **Memory** (`SemanticMemory`, `InMemorySemanticMemory`).
- **Tracing** (`Tracer`) — operational events only, never chain-of-thought.
- **Pattern router** (`select_pattern`) — picks the minimal architecture.

The runtime is **provider-neutral**: model access is injected via a
`ModelAdapter`, so it has no dependency on any LLM SDK.

## Install (dev)

```bash
pip install -e ".[dev]"
pytest -q
```

## Versioning

Generated agents pin an exact runtime version (`stack32-agent-runtime==X.Y.Z`)
so a runtime upgrade never silently changes a deployed agent's behavior.
